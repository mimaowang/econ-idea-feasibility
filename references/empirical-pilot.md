# 取数、识别与试跑

选择一项会改变去留的实证。先回答“这里真正能观察到什么、哪些单位提供比较”，再决定最小可用样本和估计器。对决定性的威胁做深，对其他问题保留余地。

## 取得一份能回答问题的样本

优先查官方数据、作者复现包、研究者已有资料和已授权数据库。沿最近论文的数据附录找表名、年份、版本、问卷题号或下载入口。自己获取并打开真实记录，再判断核心字段是否存在。若用国泰安等数据库，查到具体表和字段，使用已有授权获取一个适合本题的切片。遇到权限限制，找可替代的公开来源并实际核对。关键字段仍不可得时，注明已尝试的入口、缺什么、获准后哪项检查会改变决定。

在判断文件记下数据来源链接或库表、版本或访问日期、样本取法和覆盖范围。保留原始输入与可重跑的下载或提取方法。对于受限数据，按其使用条件保存获准的本地材料，记录他人在相同权限下如何提取。目录页、问卷、真实观测、可供估计的合并样本分别代表不同进展。转查备选来源时，围绕原方案缺的字段或连接键核验。若用户只要线索，给出字段位置与访问状态。若可合并性会决定去留，取足以检查键和时点的切片即可。

打开数据看关键字段的值、单位、时间与编码。按预期层级检查唯一键、重复和覆盖，核对合并两侧的分母、未匹配集中在哪些单位，以及最终分析样本。处理发生在地区层级时，百万个体背后可能只有几个可独立比较的地区，据此并结合抽样和误差相关性选择推断层级。研究动态路径还要核对两组能否按相同规则确定起算时点。例如，随机指派日两组都有，实际完成培训日只在一部分人身上出现。想估计结业后的效应，还得说明怎样为对照组确定可比的起点。若政策暴露或结果来自模型分配或插补，查输入是否机械地包含另一端变量，并尽可能用独立数据核对。

## 找一项可辩护的比较

估计前，在判断文件记下要比较的对象和时间、主结果变量及其单位、目标效应、样本、主要控制与推断层级，以及哪个替代解释最危险。以文献、制度尺度、对照组基准或政策成本为依据，事先说明多大的变化值得关心。如果缺少合理依据，报告区间覆盖的实际量级。已经看过结果才做的设计决定要如实标识。

去读与本题分配规则最相近的高质量**应用**经济学论文，优先相关顶刊或专业期刊。给出原文位置，并说明该论文靠什么变异、为什么可比、当前制度哪里相同或不同。再依据需要核对计量方法原文。控制变量说明对应哪条混杂路径，区分处理前特征、处理后的中介和选择结果。固定效应、聚类或加入更多控制各有用途，无法替代缺失的反事实。两个方向都有可能时，各写一个估计对象，只对有识别来源的方向作因果解释。

| 制度或问题所给的变异 | 能改变去留的一项检查 |
|---|---|
| 随机分配或随机鼓励 | 核实何者被随机分配、实际执行及失访。按分配比较得到 ITT，讨论实际接受的效应还需额外识别。 |
| 政策时点和受影响人群不同 | 核实施行时点、可用对照、处理前趋势精度和同期冲击。分期处理且效应异质时，选择与目标相符的组别和时期比较，说明假设在本地为何可信。[Callaway 与 Sant’Anna](https://doi.org/10.1016/j.jeconom.2020.12.001) |
| 明确门槛决定处理资格 | 确认真实分配变量和断点，核断点两侧的支持、操纵可能及其他同步跳变，再看局部效应对合理带宽是否敏感。[Lee 与 Lemieux](https://doi.org/10.1257/jel.48.2.281) |
| 一项候选工具影响实际处理 | 说明谁因工具而改变行为、工具如何分配，以及还有哪些路径能直接影响结果。看第一阶段、简化式和适用的弱工具稳健推断。即使第一阶段很强，仍需单独论证排除限制。[Angrist、Imbens 与 Rubin](https://dash.harvard.edu/entities/publication/73120378-82c1-6bd4-e053-0100007fdf3b) |
| 眼下能观察到分布、动态或经济核算关系 | 先做可复核的事实、分解或测量验证，解释它能区分哪些机制。原题若需要因果效应，再查能否补足识别事实。 |

## 用 Stata MCP 执行并判读

1. 在选题目录保存 `.do`。让脚本从该目录的明确输入重建样本、主比较和一项针对主要威胁的检查，把日志或结果表写回该目录。若已有 Stata 会话在工作，使用此题自己的命名会话。工具支持时用 `stata_manage_session(action="create", session_id=...)`，再以相同会话调用 `stata_run(code=do文件绝对路径, is_file=True, cwd=选题目录, session_id=...)`。
2. 检查实际返回状态与日志中的样本数、遗漏变量、标准误和区间。后台执行就等到完成。缺命令或执行失败，按具体报错处理。若 MCP 不可用，优先走可用的本机 Stata，再考虑能实现相同估计和推断的 R/Python，并注明实际后端。若暂时只能写出代码，就把估计标为未运行。
3. 报告效应单位、区间、样本数和独立处理或比较单位数，给出比较基准，相关时报告 p 值。稳健性针对事先最重要的威胁，例如对同一样本使用有依据的两种测量、排除一个可能主导结果的组、检验一个可信的安慰剂。先说明改动是否改变估计对象或样本，再解释系数差异。保留尝试过且影响判断的规格、失败结果和变更原因。

例如，若理论预言就业率至少上升 2 个百分点，且这是估计前确定的相关量级，估计区间为 [−0.3, 0.6] 个百分点可以削弱这条具体预测。区间为 [−4, 5] 时，两种方向和重要量级都仍有可能。此时算清增加多少独立比较单位才有望提高精度，结合取数成本决定是否值得。一个预期外的精确零效应也可能区分理论，但要回到文献核实那是否真是学界尚未排除的预测。[Abadie](https://www.nber.org/papers/w24403)
