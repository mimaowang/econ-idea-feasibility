# 查重与边际贡献

目标是找到能直接结束原题、或迫使它改写的那几篇研究。第一次检索从研究者的用语出发。后续检索可以从数据字典中的正式名称、制度实际分配处理的方式、或试跑仍分不清的两种解释重新开始。把每次检索带回同一个问题，说明新读到的论文会改变拟取的字段、可用的比较，还是对贡献的判断。

## 怎样从现象搜到近邻

1. 把想法写成白话问题，再拆出对象、结果的精确定义、候选机制和反事实。先宽搜现象，再轮换同义术语、逆向机制、理论模型中的对应概念。单独搜索能给出相同预测的理论，以及用了相同制度或变异来源的实证。后者可以是方法先例，未必与选题撞车。
2. 用互补来源交叉查。经济学期刊与 RePEc/IDEAS、NBER 或相关工作论文库适合追踪学术对话，Crossref、OpenAlex、学者主页和出版社页面便于核版本与题录。中国题同时用中文制度名、历史称呼、中文经济学期刊或知网等可访问入口查中文论文，英文检索也要覆盖其他地区的同构研究。按用户对可引用文献的边界，区分正式文献对话与其他学科提供的事实或检索线索。
3. 从强近邻向后看参考文献，向前找施引论文、作者新稿和正式发表版。检查经典母模型与近期未刊稿这两端。对可能撞题的论文逐篇打开可取得的正文或附录，记录页码、表号或命题号。合并同一论文的不同版本，若版本之间结论或样本变了，注明判断依据。摘要和索引可以带来线索，证据详细程度要足以支撑最终断言。
4. 在选题目录记下检索日期、实际检索入口、有用的中英文查询或同构术语、从哪篇追到了哪篇，以及有影响的访问缺口。新增的术语和引文开始反复指向已核论文、近期工作也已查过、剩余未读项不足以推翻判断时即可收束。一篇原文已明确覆盖原题且用户没有主张额外贡献时，可提前停止。数据库访问失败要换入口，零条返回本身不能证明新颖。

## 如何读足以改变判断的论文

给每篇强近邻留一行即可。记录**它问什么｜识别或推导出什么｜原文位置与链接｜它留下的具体问题**。对于理论，核对其假设是否已能推出你的结论，包括原文没有用你的术语命名的推论。对于实证，核对估计对象、样本与时间尺度、处理如何分配、核心证据能排除哪些解释。结果“不显著”的论文同样可能已经回答了你的问题。若同一事件的两篇论文结论相反，具体说明你的数据能否判别分歧来自样本、测量还是机制。工作稿和期刊论文分别标明状态。

**替研究者做一次反推。** 假如最近那篇完全正确，你的发现会使读者改变哪一个判断？一个有内容的答案可以是区分原论文无法区分的两种机制、测到原数据混在一起的两个经济量，或利用制度差异识别出原结论为何失效。说明新解释与既有解释分别预言什么，以及哪一个观测能使它们分开。仅列新地区、新年份、更多控制或另一种估计器时，追问这些变化为何足以改变经济结论。没有理由就停止原题。

例如，已有论文发现地方政策提高本地企业数。若新题关心的是净创业还是企业迁址，两种解释都预测企业数上升，但对跨地迁入、原地新设的预测不同。先核近邻是否已经分解了二者，再查登记数据是否真的记录迁址沿革。这一步会同时改变对贡献和对数据的判断。
