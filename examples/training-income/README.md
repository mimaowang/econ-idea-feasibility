# 培训结束后，收入在第几个月恢复？

**停止用 NSW 的这份公开样本研究逐月恢复，保留原题。** 实验分组能用来比较 1978 年的总收入，但文件没有月收入或个人结业日期。我们随后核对了另一项培训项目的公开记录，找到了可以按月追踪的收入。要估计培训使收入提前多久恢复，还需要为未参训者确定可比的起算时间。

## 先看最接近的研究

“培训的影响会随时间变化”已有直接证据。Vooren 等从开训月开始画出月收入轨迹。Burlat、Gilles 与 L’Horty 从培训结束起逐月比较就业情况，工资则按 3、6、12 个月累计。原题仍可追问，收入回升来自更早重新就业，还是来自较晚开始的一份高薪工作。两条路径可能有相同的半年累计收入。[Vooren 等，图 3](https://doi.org/10.1007/s10645-022-09408-6) · [Burlat 等，表 2](https://tepp.eu/images/pdf/working-paper-2025/employabilityunemployedpeoplenewtrainingprogram.pdf)

## 445 人的年度收入比较

Dehejia 和 Wahba 公开的 NSW 实验子样本包含 185 名处理组男性和 260 名实验对照组男性。收入以 1982 年美元计，零收入保留。以下两项估计都使用全部 445 人和个体层面的异方差稳健标准误。

| 比较 | 1978 年收入差异 | 95% 置信区间 |
| --- | ---: | ---: |
| 实验分配组均值之差 | 1,794.34 美元 | 475.95 至 3,112.74 美元 |
| 同一样本，加入八项处理前特征 | 1,676.34 美元 | 346.27 至 3,006.42 美元 |

控制变量为年龄、受教育年数、黑人、西语裔、已婚、无高中学历，以及 1974 和 1975 年收入。两个估计都指向正的年度差异，却无法分辨最初几个月的收入路径。[Stata 脚本](nsw.do) · [运行日志节选](stata-output.txt) · [完整估计表](nsw_results.csv)

## 换用逐月数据后，还缺什么

在美国 National JTPA Study 的公开档案中，我们把随机分配、服务记录和逐月收入三张表按参与者连接起来。有 8,388 人同时出现在三份记录中。其中 6,245 人在最后一项服务结束后的十二个完整日历月里，每月都有有效收入记录。这个人数衡量的是字段覆盖，其中也包括求职协助等服务以及提前退出者。[发行机构与数据文档](https://www.upjohn.org/data-tools/employment-research-data-center/national-jtpa-study) · [复核汇总人数的脚本](check_monthly_coverage.py)

对完成培训的人，可以描述他们后来的收入轨迹。要作因果比较，还得查清楚课程安排是否在随机分配前已经确定，让两组都能对应到同一预定结业月。若实际结业时间取决于有没有提前找到工作，只比较实际结业者就会改变两组的构成。

## 如何复跑

在 Stata 中把工作目录设为本示例目录，运行 `do nsw.do`。脚本从作者处下载数据到 `data/`，生成 `nsw_results.log` 和 `nsw_results.csv`。本例的 NSW 数据来自 LaLonde（1986）及 Dehejia 与 Wahba（1999、2002），发布者要求署名并限非商业使用。[原始数据、论文及使用条件](https://users.nber.org/~rdehejia/nswdata2.html)

要复核 JTPA 的覆盖人数，在安装了 pandas 的 Python 环境中运行 `python check_monthly_coverage.py`。脚本下载发行方约 128 MB 的公开档案，只输出汇总人数。已有该压缩包时，可把文件路径作为唯一参数传入。
